## ✨ Features
* **Responsive Layout:** Engineered with fluid CSS Grid and Flexbox layouts, fully adapted for mobile, tablet, and desktop screens.
* **Featured Projects:** Showcases core software projects with tech stack badges and direct open-source repository links.
* **Interactive UI:** Dynamic scroll-to-top feature, smooth navigation scrolling, keyframe hero animations, and glowing hover states.
* **Form Validation:** Client-side JavaScript validation using regular expressions and dynamic status feedback.
* **Accessible & Fast:** Optimized semantic HTML structure and clean JavaScript event delegation.

---

## 🛠️ Tech Stack & Tools
* **Frontend:** HTML5, CSS3 (Grid & Flexbox), Vanilla JavaScript (ES6+)
* **Version Control:** Git & GitHub
